# Apex Price Server

سيرفر يجلب أسعار السوق من **Binance** مرة واحدة كل بضع ثوانٍ، يخزّنها (cache)، والمستخدمون **يقرأون من سيرفرك أنت** وليس مباشرة من Binance. هذا هو الحل الصحيح لتجنّب الحظر: طلب واحد منك بدل آلاف الطلبات من كل مستخدم.

## المميزات
- **Proxy + Cache** لأسعار Binance (BTCUSDT, ETHUSDT, …).
- **Rate Limiting** لحماية الـ API من الاستغلال (120 طلب/دقيقة لكل IP، وحد أصرم للعمليات الحساسة).
- **تأمين** عبر helmet (security headers) + CORS + تحديد حجم الطلب.
- **تنبيهات تغير ±5%** للعملات الأساسية (BTC / ETH).
- **محفظة** تعرض الرصيد + نسبة الربح + ربح آخر 24 ساعة محسوبة من الأسعار الحقيقية. **الإيداعات لا تُحتسب ربحًا**، وكل حساب جديد يبدأ برصيد **صفر**.

## التشغيل
```bash
npm install
cp .env.example .env   # عدّل الإعدادات إن لزم
npm start
```
ثم افتح: `http://127.0.0.1:3000` للأسعار، و `http://127.0.0.1:3000/wallet.html?u=demo-user` للمحفظة.

> السيرفر يربط على `127.0.0.1` افتراضيًا (آمن للتطوير). عند النشر على خادمك، ضعه خلف عكسي proxy (Nginx/Caddy) مع HTTPS.

## ربط الـ API (معدّ مسبقًا)
بيانات الأسعار العامة من Binance **لا تحتاج مفتاح API** — السيرفر جاهز ويعمل مباشرة بعد `npm start`. يستخدم نقطة `GET /api/v3/ticker/24hr` من Binance.

### نقاط الوصول (يقرأ منها المستخدمون من سيرفرك)
| Method | Path | الوظيفة |
|---|---|---|
| GET | `/api/prices` | كل الأسعار المخزّنة |
| GET | `/api/prices/:symbol` | سعر عملة محددة (مثل `BTCUSDT`) |
| GET | `/api/alerts` | تنبيهات التغير ±5% |
| GET | `/api/wallet/:userId` | ملخص المحفظة (ديمو) |
| GET | `/api/health` | حالة السيرفر |

مثال استهلاك من الواجهة:
```js
const res = await fetch('https://your-domain.com/api/prices');
const { data } = await res.json();
```

## ملاحظات أمنية مهمة (اقرأها)
- نقاط `/api/wallet/*` هي **ديمو بدون مصادقة** وتخزينها في الذاكرة فقط. **لا تنشرها كما هي**. قبل الإنتاج: أضف تسجيل دخول (auth) + قاعدة بيانات حقيقية + سجل تدقيق (audit log).
- للحماية من الاختراق: فعّل HTTPS، 2FA، تحقّق من المدخلات، واحتفظ بالأسرار في متغيرات بيئة (لا تضعها في الكود).

## حول حساب الربح
`profit = القيمة السوقية للأصول − تكلفة شرائها`. الإيداعات رأس مال وليست ربحًا. ربح 24 ساعة يُشتق من نسبة تغير السعر الحقيقية لآخر 24 ساعة.
