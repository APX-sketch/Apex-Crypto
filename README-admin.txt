Apex — لوحة الإدارة + طلبات التسجيل + الدعم الفني
==================================================

الملفات في هذه الحزمة:
  server.js                         → استبدل ملف الخادم الحالي به (يحتوي كل شيء القديم + الجديد)
  lib/store.js                      → ملف جديد: ضعه داخل مجلد lib بجانب server.js
  public/login.html                 → صفحة تسجيل الدخول (تتصل بالخادم)
  public/register.html              → صفحة إنشاء حساب (الطلب يذهب للإدارة للمراجعة)
  public/admin.html                 → لوحة الإدارة الشاملة
  public/index.html                 → الرئيسية + زر "فريق الدعم" العائم والمحادثة
  public/trading.html               → التداول (كما هو)
  public/futures.html               → العقود (كما هو)
  public/lib/lightweight-charts.js  → مكتبة الرسم المحلية

الملفات الأخرى في مجلد lib عندك (priceCache.js, portfolio.js, marketCache.js,
binanceProxy.js) تبقى كما هي — لا تحذفها.

التشغيل:
  1) ضع الملفات في أماكنها كما بالأعلى.
  2) شغّل الخادم:  npm start   (أو  node server.js)
  3) افتح:  http://127.0.0.1:3000

بيانات الأدمن الافتراضية (غيّرها فوراً):
  المستخدم: admin
  كلمة المرور: apex-admin-2024
  للتغيير عبر متغيرات البيئة قبل التشغيل:
    ADMIN_USER=اسمك  ADMIN_PASS=كلمة_قوية  node server.js

خيارات:
  REQUIRE_APPROVAL=false  → يوافق تلقائياً على الحسابات الجديدة بدون مراجعة.

صفحة الأرصدة والسيولة (جديد):
- من لوحة الإدارة افتح "الأرصدة والسيولة" من القائمة الجانبية.
- تعرض لكل حساب: الاسم والبريد والرصيد مقيّماً بالدولار (USD) + الحالة (نشط/غير نشط) + آخر ظهور، مع بطاقة إجمالي السيولة.
- الأرصدة تُقيّم بأسعار سيرفرك اللحظية؛ الصفحات ترسل أرصدتها للخادم كل 12 ثانية.

ملاحظات أمنية مهمة (النسخة تجريبية):
  - كلمات المرور مُشفّرة (scrypt) والجلسات برموز عشوائية، لكن التخزين في ملف
    JSON واحد (data/apex-data.json). للإنتاج استخدم قاعدة بيانات + HTTPS + توثيق أقوى.
  - غيّر كلمة مرور الأدمن قبل أي استخدام حقيقي.
  - صفحة admin.html مكشوفة على المسار /admin.html؛ الحماية عبر تسجيل دخول الأدمن فقط.
